## 本階段目標

將已完成的借用人 OTP／30 天裝置信任流程連接到借用申請表，啟用設備選擇、數量、借用日期、用途與申請送出。

## 已完成的程式變更

- 設備清單載入後建立設備下拉選單；設備清單失敗或沒有可用設備時保持停用。
- 借用表單加入數量欄位與日期先後檢查。
- 送出前要求目前 Email 已經由 OTP 驗證或後端確認為受信任瀏覽器。
- 若本機有裝置信任憑證，將其隨 `borrow.create` POST JSON body 送往後端；不把憑證放入 URL。
- 加入安全亂數冪等鍵、重複送出鎖定、相同表單資料重試沿用同一冪等鍵。
- 成功後顯示申請編號與待審核狀態；錯誤訊息以 textContent 顯示。
- 信任啟用狀態不明或失敗時，不允許前端僅憑本機狀態送出申請。
